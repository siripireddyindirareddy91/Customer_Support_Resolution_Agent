# Project requirements

The target application provides delivery support for tracking, exceptions, damaged/wrong/missing items, refunds, cancellations, replacements, policy questions, and human escalation. Resolutions must use verified customer/order data and applicable policy evidence. An LLM must not independently authorize financial or irreversible operations.

The current increment proves the core tracking and policy-guidance workflow, customer scoping, safe escalation, and a customer chat surface. Persistent storage, workflow memory, full intent coverage, and operational mutation flows are not included yet.
