# Functional requirements

## Delivered in this increment

- Customer tracking lookup and delivery status from seeded order records.
- Delivery and general policy guidance from local Markdown sources.
- Human-request escalation state.
- Bounded intent fallback with optional structured model classification.
- Signed demo bearer authentication and customer/order isolation.
- Workflow activity and structured resolution returned to the chat UI.

## Not delivered yet

- Persistent accounts, orders, tickets, conversations, audit logs, and resolutions.
- Refund, cancellation, replacement, damaged-item evidence collection, and agent operations.
- Admin analytics, order/ticket detail pages, SSE streaming, and production login.
- Full document ingestion and semantic/hybrid RAG.
